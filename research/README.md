# TAA Research Vault

Obsidian-based knowledge graph for tracking TAA system research experiments, findings, and architectural decisions.

Open this folder as an Obsidian vault to browse the knowledge graph.

## Structure
- **context/** — Living documents tracking cumulative project knowledge
- **experiments/** — One file per experiment with results, interpretation, and links
- **decisions/** — Records of why each approach was adopted or rejected  
- **templates/** — Standard formats for new experiments and decisions
